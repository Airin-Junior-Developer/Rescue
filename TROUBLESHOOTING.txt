# 🛠️ คู่มือแก้ปัญหาเบื้องต้น (Troubleshooting Guide) - Rescue Project

ไฟล์นี้รวบรวมปัญหาที่พบบ่อยระหว่างการพัฒนาและเปิดใช้งานระบบ พร้อมวิธีแก้ไขแบบรวดเร็วครับ

---

## 1. ปัญหา: Backend รันแล้วขึ้น Error สีแดง `ECONNREFUSED 127.0.0.1:3306` หรือ `6379`
**อาการ:** รัน `npm run dev` ใน `rescue-backend` แล้ว Terminal ร้องเตือนรัวๆ และระบบไม่สามารถทำงานได้
**สาเหตุ:** ฐานข้อมูล MySQL (3306) หรือ Redis (6379) ยังไม่ได้เปิดทำงาน
**วิธีแก้:**
1. เปิด Terminal ใหม่ (หรือหยุด Backend ก่อน)
2. เข้าไปที่โฟลเดอร์แบคเอนด์: `cd rescue-backend`
3. สั่งรันฐานข้อมูลด้วยโปรเจกต์เดิม: **`docker-compose -p rescue up -d`**
4. รอจนขึ้น `Started` แล้วค่อยไปรัน `npm run dev` อีกครั้ง

---

## 2. ปัญหา: หน้าเว็บเข้าไม่ได้ ขึ้น `ERR_SSL_PROTOCOL_ERROR` หรือ `Your connection is not private`
**อาการ:** เข้าเว็บฝั่ง Frontend แล้วหน้าเว็บเตือนเรื่องความปลอดภัย (SSL) หรือเข้าไม่ได้
**สาเหตุ:** Browser บล็อกใบรับรองจำลอง (Fake SSL) ของ Vite หรือมีการเรียก `https://` แต่ระบบรันเป็น `http://`
**วิธีแก้ (สำหรับตอนพัฒนา):**
- **สูตรลับ Chrome:** หากหน้าจอขึ้นเตือนความปลอดภัย ให้คลิกซ้ายที่พื้นที่ว่าง 1 ครั้ง แล้วพิมพ์คำว่า `thisisunsafe` ทันที (พิมพ์บนคีย์บอร์ดเลย ไม่ต้องหาช่องกรอก) ระบบจะข้ามการบล็อกให้ทันที
- **กรณีปิด SSL ไปแล้ว:** ตรวจสอบ URL ด้านบนให้แน่ใจว่าพิมพ์เป็น **`http://`** (ไม่มี s) และเข้าไปแก้ Endpoint URL ใน **LINE Developers Console** เป็น `http://` ด้วยเช่นกัน

---

## 3. ปัญหา: หน้า Admin Dashboard โหลดค้าง หรือแสดงข้อมูลว่างเปล่า
**อาการ:** ล็อกอินเข้าหน้า Admin แล้ว แต่ตารางสถิติต่างๆ ไม่ขึ้น หรือหน้าเว็บค้าง
**สาเหตุ:** เกิดจากการรัน `server.js` ก่อนที่ฐานข้อมูลจะพร้อมใช้งาน ทำให้คำสั่งสร้างคอลัมน์ใหม่ (Auto-Migration) ทำงานล้มเหลว
**วิธีแก้:**
1. ตรวจสอบให้แน่ใจว่าฐานข้อมูลทำงานอยู่ (`docker-compose -p rescue up -d`)
2. ปิด Terminal ที่รันแบคเอนด์อยู่ (กด `Ctrl + C`)
3. สั่งรัน `npm run dev` ในโฟลเดอร์ `rescue-backend` ใหม่ เพื่อให้ระบบรันคำสั่ง Migration (เช่น การเพิ่มคอลัมน์ `cancel_reason`) อีกครั้ง
4. รีเฟรชหน้าเบราว์เซอร์ฝั่ง Admin

---

## 4. ปัญหา: ฝั่งประชาชน (Citizen) ระบบไม่ยอมดึงเบอร์โทรศัพท์มาให้อัตโนมัติ
**อาการ:** เข้าใช้งานผ่าน LINE แต่ระบบยังบอกให้ "กรอกเบอร์โทรสำหรับการใช้งานครั้งแรก"
**สาเหตุ:** ไม่ใช่บัคครับ! ระบบของ LINE ไม่อนุญาตให้ดึงเบอร์โทรตรงๆ ผู้ใช้จะต้องกรอกเบอร์เองใน "การใช้งานครั้งแรก" เท่านั้น
**วิธีแก้:**
- ให้ผู้ใช้กรอกเบอร์โทร และกดแจ้งเหตุ SOS 1 ครั้ง 
- ข้อมูลจะถูกบันทึกผูกกับบัญชี LINE ทันที และในการเข้าใช้งานครั้งต่อๆ ไป ระบบจะดึงเบอร์โทรมาใส่ให้อัตโนมัติ

---

## 5. ปัญหา: Port ชนกัน (Address already in use)
**อาการ:** รัน `npm run dev` แล้วขึ้น Error ว่า Port `5173`, `3000`, หรือ `3002` ถูกใช้งานอยู่แล้ว
**สาเหตุ:** คุณอาจจะเปิด Terminal ทิ้งไว้ซ้อนกัน หรือเผลอรันโปรเจกต์เดิมค้างไว้
**วิธีแก้:**
- ให้หา Terminal หน้าต่างเก่าที่รันค้างไว้แล้วกด `Ctrl + C` เพื่อหยุดการทำงาน
- หากหาไม่เจอ สามารถฆ่าโปรเซสที่ใช้พอร์ตนั้น (ใน Mac) ด้วยคำสั่ง:
  `kill -9 $(lsof -ti:3000)` (เปลี่ยนเลข 3000 เป็นพอร์ตที่มีปัญหา)
