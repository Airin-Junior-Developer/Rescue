# Rescue Connect

ระบบสาธิตการประสานงานกู้ภัยสำหรับการเรียนการสอน ประชาชนแจ้งเหตุผ่าน LINE ทีมกู้ภัยรับงานและส่งตำแหน่ง ส่วนผู้ดูแลติดตามเคสผ่านเว็บแยก

**สำหรับอาจารย์** เริ่มจาก [สาขา main](https://github.com/Airin-Junior-Developer/Rescue/tree/main) แล้วเปิด [คู่มือติดตั้งภาษาไทย](docs/HANDOFF-TH.md) คู่มือมีขั้นตอนสร้างฐานทดลอง บัญชีเข้าใช้ทั้ง 4 บัญชี และวิธีผูก LINE ของสถาบัน เมื่อเข้าสู่ระบบได้แล้ว ให้ใช้ [ลำดับสาธิตและคู่มือดูแล](docs/DEMO-TH.md)

สาขา main รุ่นส่งมอบใช้ schema ว่างและบัญชีสาธิต ประวัติเวอร์ชันเก่าของ repo ยังมี dump ฐานข้อมูลที่มีข้อมูลประชาชน ผู้มีสิทธิ์อ่าน Git สามารถย้อนดูได้ สาขาเก่าบางสาขายังมีไฟล์ดังกล่าว หากต้องแจกเฉพาะรุ่นนี้ ให้ใช้ [ชุด ZIP จาก main](https://github.com/Airin-Junior-Developer/Rescue/archive/refs/heads/main.zip) หรือสร้าง repo ของสถาบันจากไฟล์ใน ZIP ด้วย Git history ใหม่ การ fork จะเก็บประวัติเดิม

หากต้องการให้สถาบันดูแล Git ต่อโดยไม่มีประวัติเดิม ให้แตก ZIP ลงโฟลเดอร์ใหม่ รัน `git init -b main`, `git add .` และ `git commit -m "Import Rescue classroom handoff"` ก่อนตั้ง remote ไปยัง repo ว่างของสถาบัน ทำขั้นนี้ก่อนสร้างไฟล์ตั้งค่าจริง
